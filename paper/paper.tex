\title{Does Agentic Architecture Discovery Reproduce? An Audit Gate That Blocked Its Own Headline Result}
\author{Anonymous Submission}
\affiliation{\institution{Anonymous}\country{Anonymous}}

\begin{abstract}
Agents already \emph{discover and exploit loopholes in microarchitectural simulators}~\cite{archagent}, so we measure evaluation validity rather than design discovery. We release a CHIA audit loop that separates four variance sources an aggregate score hides (repeated-run, generation-seed, prompt and trace) and gates publication on a pre-registered threshold plus a double-blind annotation layer. Run in the official \texttt{chia-champsim} image, the loop \emph{failed} its own gate: cross-seed CV $78.16\%$ against a $5\%$ threshold within one generated series, while repeated-run CV is $0.0000\%$ over 45 runs, so the publish gate reads \textsc{Blocked}. Two candidates differing only in a struct name carry distinct source, design and binary digests yet bit-identical cycles: the seed moved the artifact, not the design. Annotation gives $\kappa=0.859$ on specification diffs and $0.636$ on real generated C++, both below our own 0.7 gate; on six measurement-grounded pairs two same-provider models never disagree yet each is right on only 3 of 6, and a second provider reproduces those three misses, all of them simulator escapes. Auditing that $\kappa$ found the defect inside it: our own label generator read \texttt{\#include} angle brackets as comparison operators and mislabelled three rename-only pairs, so the annotators we were scoring were correct and the ground truth was not. We report the negatives, ten defects found in our own automation, and the repairs instead of moving thresholds.
\end{abstract}

\maketitle

\section{Introduction}
\label{sec:intro}

Architecture 2.0 pipelines (ArchAgent~\cite{archagent}, CHIA~\cite{chia}, QuArch) let agents propose and evaluate designs with no human in the loop, and the risk is not unclaimed: ArchAgent reports that its own pipeline found and exploited a loophole in a popular microarchitectural simulator, inflating reported performance without changing hardware logic~\cite{archagent}. Software-side evaluation shows the same fragility: the top three Terminal-Bench~2 submissions were all caught cheating via harness tricks~\cite{meerkat}, OpenAI dropped SWE-bench Verified after an audit found roughly $30\%$ of SWE-bench Pro's tasks broken~\cite{swebench}, and an automated audit of 168 agent benchmarks flags over $25.7\%$ of the evaluated \emph{tasks}~\cite{autobench}.

What is missing is an instrument, not another warning: a loop that runs against a real simulator, separates the variance sources an aggregate score hides, and refuses to publish when that separation fails. We contribute that loop plus what it said about us: a \textsc{Blocked} verdict on our own headline claim (\S\ref{sec:repro}), seeds moving artifacts without moving designs, trace-dependent reordering (\S\ref{sec:trace}), prompt response at $249.18\%$ (\S\ref{sec:prompt}), a failure mode text-reading auditors cannot catch and a second provider repeats (\S\ref{sec:escape}), and ten defects in our own automation (Table~\ref{tab:defects}). Each was found by reading evidence, none by a green gate.

\section{The Audit Loop}
\label{sec:loop}

\textbf{Prepare.} Pin git SHA, interpreter and image digest; load the pre-registered configuration. Thresholds are frozen before any measured cell exists, which is what makes the \S\ref{sec:results} verdicts binding. \textbf{Run.} Execute a $|\text{seeds}|\times|\text{prompts}|\times|\text{traces}|$ grid, $n$ repeats per cell, through CHIA's \texttt{ChampSimNode} in the official image, recording the candidate digest, delivered binary digest and raw simulator JSON per cell. \textbf{Audit.} Two annotators classify candidate against reference using E0--E4: E0 equivalent, E1 parameter mislink, E2 direction error (LRU$\leftrightarrow$MRU), E3 missing component, E4 added or fabricated component. The payload is built from an allowlist of \texttt{id}, \texttt{design}, \texttt{reference}, and the script refuses to run if any expected label survives. \textbf{Act.} Emit the scorecard and gate: \texttt{publishable} requires reproducibility \textsc{Pass} \emph{and} audit \textsc{Pass}. A nullity check compares each candidate with a no-op reference measured on the same trace and instruction budget. The in-loop self-test and the independent-model layer are reported separately and never merged.

\textbf{Setup.} \texttt{ghcr.io/ucb-bar/chia-champsim} at digest \texttt{sha256:610951d3\ldots}, ChampSim \texttt{164fdb1e\ldots}, Python 3.10.19, Ray 2.54.0; 46 unit tests pass in-tree and inside the pinned image. Grids ran on two \texttt{c2d-standard-8} VMs in \texttt{us-east1-b}; on the three (design, trace) cells where they overlap they agree to the cycle. Three DPC-4 traces (fotonik3d, ligra BFSCC, imagick) with SHA-256 in \texttt{results/grid\_v6/provenance.json}, 1M warmup + 4M simulated instructions, L2C. Candidates are real LLM-generated prefetcher modules retained with raw prompts and responses; seeds and prompts select the artifact and the simulator is never handed a seed. A separate $3{\times}3$ prompt-by-seed factorial exercises the prompt axis: \textbf{6 of 9} generated candidates compile, and all three failures abort within ${\approx}13$\,s against ${\approx}800$\,s for a cold success. \textbf{Calibration.} 5 gold + 5 adversarial specification cases and 4 semantic cases built from the generated C++ itself. Pre-registered: cross-seed CV $<5\%$; repeated-run CV, prompt spread, trace CV, top-1 stability and leave-one-trace-out Kendall $\tau$ reported; annotation gate $\kappa\geq0.7$.

\textbf{Release.} A harness that only ever returns \textsc{Pass} cannot be distinguished from one that is not looking, so the artifact ships the blocked scorecard, raw cells and digests: loop, cases, generators, gate and \texttt{scripts/independent\_audit.py} as CHIA-compatible blocks (BSD-3-Clause). The repository URL is filed in the submission form rather than printed here, so the paper stays anonymous. Every number quoted here is re-derived from the committed artifacts by \texttt{scripts/verify\_paper\_claims.py} (241 claims, non-zero exit on drift), The full audit report behind Table~\ref{tab:defects} ships in the same repository as \texttt{paper/paper\_extended.tex}. Reproduce the headline grid with\\
\texttt{python3 chia\_loop/loops/audit\_repro.py --version 6 --config .tmp/cfg/grid\_gcp.json --backend champsim\_node --output-dir /tmp/repro},
passing an output directory outside \texttt{results/} so a replication cannot overwrite the committed evidence. Both compute hosts and the sponsoring account were deleted on 2026-09-24.

\section{Results}
\label{sec:results}


\subsection{The gate blocked our own headline claim}
\label{sec:repro}

Across 3 designs $\times$ 3 traces $\times$ 5 repeats (45 runs, on a second physical host) the loop reports cross-seed CV $\mathbf{78.16\%}$ against the 5\% threshold, verdict \textsc{Non-Reproducible}, publish gate \textsc{Blocked}. Repeated-run CV is $\mathbf{0.0000\%}$: no cell varies across its five runs. The simulator is deterministic, and determinism is not reproducibility (the variance decomposition of Fig.~1 in the full report).

Cycles, IPC and instruction counts match the earlier run on all nine cells, yet \textbf{0 of 9} cells share a delivered binary digest: a rebuild on another host produces byte-different binaries while the simulated measurement stays bit-identical. A binary digest therefore evidences a distinct build, not design identity, and a gate demanding digest equality across hosts would reject a faithful reproduction. The converse failure is in our own screening data: module \emph{names} are not identifiers either. \texttt{gen\_fill\_only\_conservative\_s2} occurs in both batches under different delivered binaries, measuring $1{,}132{,}568$ and $1{,}129{,}110$: a join keyed on the name silently drops one.

The seed axis explains the gap. \texttt{s1} and \texttt{s3} differ only in the struct name and two lines of continuation indentation, yet each carries a different source, design and binary digest while all three traces return bit-identical cycles. \texttt{s2} keeps a fill history, is 10.6\% faster than the no-op reference on BFSCC, and reproduces the no-op cycle count exactly on imagick. The seed moved the artifact and not the design, and nullity is a per-trace property, so the evidence checker now separates \texttt{null\_on\_every\_measured\_trace} from trace-dependent inertness.

That $78.16\%$ is scoped to one generated series, and a second series says why. A replication of the same prompt at seeds $\{2,3\}$ from a \emph{different} candidate directory measures cross-seed CV $\mathbf{0.0000\%}$, because the two directories hold different programs under the same module name (BFSCC cycles 6{,}420{,}195 versus 95{,}624{,}440). The $15\times$ gap is an input difference, not a measurement disagreement, and only the distinct \texttt{candidate\_sha256} values made it checkable: a seed label is not a design identifier across series.

\subsection{Trace choice reorders the candidates}
\label{sec:trace}

Trace CV is $163.33\%$, top-1 stability $0.667$, mean Kendall $\tau=0.556$: the ranking is not stable under the trace subset that produced it. The control pair separates by 23.15\% on BFSCC but 0.42\% on fotonik3d, so the grid must be read per trace. And the stability number is not stable either: a second rectangle, $2\,\text{seeds}\times2\,\text{prompts}\times3\,\text{traces}$ (12 cells, 36 runs), same harness, same pinned image, same traces, reports top-1 stability $\mathbf{1.0}$ and $\tau=\mathbf{0.778}$ over four designs. Nothing in the instrument changed; only the candidate set did. So $\tau=0.556$ and $\tau=0.778$ are both correct readings of the same code, and ``the ranking is unstable'' is a claim about a design set, not about agentic architecture discovery.

\subsection{Prompt sensitivity is 249\%, and the gate could not see it}
\label{sec:prompt}

A separate $1\,\text{seed}\times3\,\text{prompt}$ grid over three traces gives maximum prompt spread $\mathbf{249.18\%}$, computed as $(\max-\min)/\text{mean}$; the spread is almost entirely one trace. The two axes do not mask each other: the $2\times2$ rectangle measures cross-seed CV $\mathbf{23.50\%}$ and prompt spread $\mathbf{179.67\%}$ simultaneously, both far above the $5\%$ gate.

The same grid carries a second, worse story. Because it held the seed constant, cross-seed CV was computed over a single value, and our variance helper returns $0.0$ for fewer than two samples, so the scorecard printed $\text{cross-seed CV}=0.0000\%$, watched it satisfy the $<5\%$ threshold, and returned \textsc{Reproducible}/\textsc{Publishable}. \textbf{An axis that never varied cannot fail a threshold on that axis}, and our gate could not tell a measured $0\%$ from an unmeasured one. The fix counts factor levels: an axis with fewer than two levels is \emph{unexercised}, can never satisfy the gate, and is named in \texttt{publish\_blockers} as \texttt{axis\_not\_exercised:seed}. \texttt{scripts/rescore\_grid.py} then rescored every retained \texttt{raw.json} without re-running the simulator; the verdict is \textsc{Non-Reproducible}/\textsc{Blocked}.

\subsection{Independent annotators, and a shared blind spot two providers reproduce}
\label{sec:audit}

On the 10 specification cases the two models give Cohen's $\kappa=\mathbf{0.859}$ (0.900 agreement; verdict accuracy 10/10, error-code exactness 7/10 and 8/10). Widening to pairs of the nine factorial candidates, built from real generated C++ rather than dictionary diffs, gave $\kappa=0.7235$ over 36 pairs; Table~\ref{tab:defects} row 2 shows why that cannot be quoted. After relabeling, \textbf{33 of 36} pairs carry a derivable verdict, both annotators are correct on \textbf{all 33}, they never disagree ($\kappa=1.0$ on verdict), and combined-label $\kappa$ falls to $\mathbf{0.636}$. That is below our own 0.7 gate too, so both external sets are red: 0.7235 was the only value that passed, and it passed on withdrawn labels. On the \textbf{six} measurement-grounded cases the two models do not disagree (0 disagreements), and each is right on only 3 of 6 (verdict accuracy $\mathbf{0.5}$); combined-label $\kappa$ is $\mathbf{0.455}$. The three cases they miss together are \emph{exactly} the three escapes of \S\ref{sec:escape}, and no escape is missed by only one of them.

One caveat we cannot resolve: \textbf{all 33 labellable gold labels in that set are \texttt{not\_equivalent}}, so a constant \texttt{not\_equivalent} rater would also reach $\kappa=1.0$, and our helper returns exactly 1.0 on degenerate marginals. The verdict-only row is therefore \emph{not} evidence of reliability; the 0.636 is. And high verdict agreement is the warning, not the reassurance: $\kappa$ measures correlation between annotators, not correctness against measurement. $\kappa=1.0$ is what a shared blind spot looks like from the inside, and also what a shared \emph{correct} reading looks like when the ground truth is the defective party.

\subsection{A nullity escape both auditors missed, and a second provider repeats}
\label{sec:escape}

Compile-and-run is not evidence of a design. Against a cold no-op reference (the nullity screen of Fig.~1b in the full report) measuring 1{,}138{,}748 cycles, two \emph{distinct} binaries (a generated stride prefetcher and a repaired aggressive-offset candidate) return exactly 1{,}138{,}748, while every genuine prefetcher and the next-line control differ. A separate screening of the factorial added a third: \texttt{gen\_aggressive\_offset\_s1}. Three nullities across two batches: any verifier accepting ``builds, runs, produces numbers'' passes all three.

Both annotators classified this case \texttt{not\_equivalent}/\textbf{E4}; measurement says \texttt{equivalent}. They agree with each other and disagree with the simulator. Three of the six measured cases are nullity escapes, from two screening batches and three distinct binaries; both raters miss \textbf{all three} in the same direction and miss none of the other three. That is a systematic blind spot, not independent noise, on a denominator of six. Nor is it an artefact of framing: swapping candidate and reference leaves all twelve verdicts unchanged ($0/12$ flips, \texttt{scripts/annotation\_role\_swap.py}). E0--E4 has no slot for ``claims to work, measurably does nothing'': it audits pairwise specification difference, whereas the escape is a claim-to-measurement gap. What catches it is the nullity check, not the taxonomy.

That account rests on two raters who share a provider, so we put the same question to a second provider, \texttt{Atria-Dawn-Preview} at \texttt{temperature} 0, shown payloads carrying the published raters' own prompt digests so prompt drift cannot explain any agreement between them. It reproduces the blind spot rather than breaking it. On the six measured cases it recovers 3 of 6 verdict labels and 1 of 6 error-code labels, and the three verdicts it misses are exactly the three escapes, each returned as \texttt{not\_equivalent}/\textbf{E4}. On the 36 real-source pairs they agree completely where a label exists: on the 33 labellable pairs all three reproduce the recorded verdict (\textbf{33/33} each) and separate only on the error codes, matching the recorded set on 7, 9 and 6 of those same 33, with 26 of the 27 second-provider misses strict supersets of it. On the three \texttt{unlabellable} pairs every rater answers \texttt{equivalent}: none abstains where the rubric derives nothing. Agreement about \emph{which} code fired, not about equivalence, is the scarce quantity. Switching providers buys coverage of a different failure mode, not freedom from this one. \texttt{scripts/rater\_rollup.py} re-derives every number here from the per-case labels and refuses the artifact on drift.

\subsection{A third substrate buys agreement, not independence}
\label{sec:substrate}

We also ran an architecturally distinct rater: a 421M ModernBERT \emph{discriminative}, non-autoregressive head, which cannot generate the rationale an audit prompt asks for. It reaches 0.5 of 10 specification and 0.667 of 6 measured cases but \textbf{0 of 33} real generated pairs, answering \texttt{equivalent} on 35 of 36, and agrees with the two generative raters at $\kappa=0.138$, $\mathbf{-0.364}$ and $-0.057$: on two of three sets it is anti-correlated with them. On the escape case it answers \texttt{equivalent}, which is \emph{correct}, at a top-1 minus top-2 margin of 0.010: right for no reason a verifier can detect. Changing substrate does not buy independence, which is a property of the \emph{evidence channel}, and only the simulator provides one here. Substituting it for the missing rater was the obvious move and not one we can make honestly, so the measured set stops at six cases.

\section{What this should change}
\label{sec:changes}
Each rule is a check an author can run; all eight were violated by us.
\textbf{(1) Report factor levels beside every variance statistic}: a spread over fewer than two levels of its own axis is \emph{unexercised} and can never satisfy a threshold. \textbf{(2) Treat labels as generated artifacts}: ground a verdict in measurement where you can, abstain where you cannot, and fuzz structural labelers against preprocessor lines and comments. \textbf{(3) Key identity on the delivered digest, and report the label marginal with every agreement statistic}: $\kappa=1.0$ on a single-class set means nothing, and a factor level whose design is another level's design measures nothing however consistent its bookkeeping. \textbf{(4) Do not let a learned score decide what needs approval} unless it is shown to separate the safe action from the destructive one; a rule that escalates everything automates nothing. \textbf{(5) Make nullity a gate, not a diagnostic}: ``compiles, runs, produces numbers'' passed three designs that do nothing, and two of them equal the no-op reference on every trace. \textbf{(6) Record a source digest beside every measurement}: a binary digest says a build happened, not which source produced it, and a module name says less. \textbf{(7) Fail closed when a factor level has no artifact}: substituting a nearby candidate to keep a grid rectangular destroys the axis both ways and leaves no trace in the labels. \textbf{(8) Re-derive, do not re-run}: every repair here was scored against replies and measurements already on disk, so a label or attribution defect cost no simulator run and no new model query.

\section{Limitations}
\textbf{Each grid is one design set.} The $2\times2$ rectangle shows the seed and prompt effects surviving simultaneous variation, but the same code reports $\tau=0.556$ then $0.778$ and $78.16\%$ then $23.50\%$ cross-seed CV, so every magnitude here is a statement about a specific set of generated designs. \textbf{Repeats:} $0.0000\%$ is $N=5$ per cell (45 runs) and proves only determinism. \textbf{Labels:} the 33-pair $\kappa$ rests on structural labels that survived our own header-parsing defect only because we could re-derive them, and no pair in that set is gold-labelled \texttt{equivalent}, so its verdict-axis agreement is degenerate rather than reliable. \textbf{Annotators:} the two generative raters the published $\kappa$ rests on share one provider; the second provider reproduces the shared error on the measured and canonical cases but not on the 33-pair set; the one architecturally different rater we could reach is worse than independent (\S\ref{sec:substrate}); and no rater here is a human. \textbf{Validity:} we tested role order ($0/8$ verdict flips) and not training-data contamination, which systematic reviews treat as the dominant risk~\cite{contamination}. \textbf{A re-ask is disclosed:} the second provider's 10-of-10 canonical verdict score is a retry's, since the first request returned no content at all and the retry, shown an identical prompt digest, parsed. \textbf{Provenance:} three historical \texttt{unknown} commits are left unrepaired, because writing a plausible SHA into a file that never measured one would be the defect itself. \textbf{Scope:} one simulator, one design family, three traces; no RTL flow and no gem5 result is claimed.

\section{Conclusion}
We released an audit loop that separates four variance sources, gates publication on measurement \emph{and} annotation, and keeps its evidence. Against the official CHIA ChampSim image it blocked its own reproducibility claim at $78.16\%$ cross-seed CV, showed seeds moving artifacts without moving designs, prompt response at $249.18\%$, and two same-provider auditors agreeing and both wrong on a measured simulator escape that a second provider repeats on byte-identical prompts. It also caught ten silent defects in our own automation, including a labeler that read \texttt{\#include} brackets as comparison operators while the annotators it scored were right. The instrument, the negative verdicts and the self-reports are the contribution.

\section*{AI assistance in this work}
AI coding and writing tools assisted with implementation, experiment plumbing, and the drafting and editing of this paper. An AI agent ran the audit loop, wrote and revised the scripts and the evidence pipeline, and drafted this text under the author's direction; the author selected the claims, checked them against the primary artifacts, and is responsible for all content. The evaluation layer is machine-generated as well: two generative raters from one provider, a third from a second provider (\texttt{Atria-Dawn-Preview}, \texttt{api.atria-asi.ai}, queried 2026-09-24 at \texttt{temperature} 0, per-case prompt digests in the artifact), a generative labeler shown to be wrong while the raters were right (Table~\ref{tab:defects} row 2), a local discriminative head used as both third annotation substrate and decision gate (\S\ref{sec:substrate}, Table~\ref{tab:defects} rows 6), and ten self-audits by the same agent that produced the code it reviewed. A generated object counts as evidence only with its producer, version and failure modes attached; the negative verdicts here came from a process that was not independently audited, so the repository is the thing to check.
