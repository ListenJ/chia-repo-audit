\title{\vspace{-1.5em}\textbf{Does Agentic Architecture Discovery Reproduce?}\\
An Audit Gate That Blocked Its Own Headline Result\vspace{-0.5em}}
\author{Anonymous Submission}
\date{}

\begin{document}
\maketitle
\vspace{-2em}

\begin{abstract}
Agents already \emph{discover and exploit loopholes in microarchitectural
simulators}~\cite{archagent}, so we measure evaluation validity rather than design
discovery. We release a CHIA audit loop that separates four variance sources an
aggregate score hides---repeated-run, generation-seed, prompt and
trace---gating publication on both a pre-registered threshold and a double-blind
annotation layer whose annotators are independent models. Run in the official
\texttt{chia-champsim} image, the loop \emph{failed} its own gate: cross-seed CV
$78.16\%$ against a $5\%$ threshold while repeated-run CV is $0.0000\%$ over 45
runs, so the publish gate reads \textsc{Blocked}. Two candidates differing only in
a struct name and indentation carry distinct source, design and binary digests yet
bit-identical cycles on all three traces: the seed moved the artifact, not the
design. Ranking is unstable (top-1 $0.667$, Kendall $\tau=0.556$). Annotation
gives $\kappa=0.859$ on specification diffs but $0.667$ on real generated C++,
where both auditors agree and are both wrong about a measured simulator escape. We
report the negatives instead of moving the thresholds.
\end{abstract}

\section{Introduction}
\label{sec:intro}

Architecture 2.0 pipelines (ArchAgent~\cite{archagent}, CHIA~\cite{chia},
QuArch) let agents propose and evaluate designs with no human in the loop. The
risk is not unclaimed: ArchAgent reports its pipeline discovered and exploited a
loophole in a popular microarchitectural simulator, inflating reported
performance without changing hardware logic~\cite{archagent}. Software-side
evaluation shows the same fragility---all top-three Terminal-Bench~2 submissions
cheated via harness vulnerabilities~\cite{meerkat}, OpenAI deprecated SWE-bench
Verified and retracted SWE-bench Pro~\cite{reprocrisis}, and $>25.7\%$ of 168
reviewed benchmarks carry critical defects~\cite{autobench}.

What is missing is an instrument, not another warning: a loop that runs against a
real simulator, separates the variance sources an aggregate score hides, and
refuses to publish when the separation fails. We contribute that loop plus what
it said about us---a \textsc{Blocked} verdict on our own headline claim
(\S\ref{sec:repro}), evidence that generation seeds move artifacts without
moving designs, trace-dependent reordering (\S\ref{sec:trace}), and a failure
mode that text-reading auditors cannot catch (\S\ref{sec:escape}).

\section{The Audit Loop}
\label{sec:loop}

\textbf{Prepare.} Pin git SHA, interpreter and image digest; load the
pre-registered configuration. Thresholds are frozen before any measured cell
exists, which is what makes the \S\ref{sec:results} verdicts binding rather than
negotiable~\cite{contamination}. \textbf{Run.} Execute a
$|\text{seeds}|\times|\text{prompts}|\times|\text{traces}|$ grid, $n$ repeats per
cell, through CHIA's \texttt{ChampSimNode} in the official image, recording the
candidate digest, delivered binary digest and raw simulator JSON per cell.
\textbf{Audit.} Two annotators classify candidate against reference using E0--E4
(Table~\ref{tab:errors}). The payload is built from an allowlist of \texttt{id},
\texttt{design}, \texttt{reference}; the script refuses to run if any expected
label survives. We report the deterministic in-loop self-test and the
independent-model layer separately and never merge them. \textbf{Act.} Emit the
scorecard and gate: \texttt{publishable} requires reproducibility \textsc{Pass}
\emph{and} audit \textsc{Pass}. A nullity check compares each candidate with a
no-op reference measured on the same trace and instruction budget.

\textbf{Setup.} \texttt{ghcr.io/ucb-bar/chia-champsim} at digest
\texttt{sha256:610951d3\ldots}, ChampSim \texttt{164fdb1e\ldots}, Python 3.10.19,
Ray 2.54.0, one \texttt{c2d-standard-8} VM (\texttt{us-east1-b}); 34 unit tests
pass inside the image. Three DPC-4 traces (fotonik3d, ligra BFSCC, imagick) with
SHA-256 in \texttt{results/grid\_v6/provenance.json}, 1M warmup + 4M simulated
instructions, L2C. Candidates are three real LLM-generated prefetcher modules
retained with raw prompts and responses, loaded through directory mode; seeds and
prompts select the artifact and the simulator is never handed a seed. A separate
$3{\times}3$ prompt-by-seed factorial was generated to exercise the prompt axis:
\textbf{6 of 9} candidates compile, taking every generated candidate as the
denominator, and all three failures abort the build within ${\approx}13$\,s
against ${\approx}800$\,s for a cold success.
\textbf{Calibration.} 5 gold + 5 adversarial specification cases plus 4
semantic cases built from the generated C++ itself. Pre-registered metrics:
cross-seed CV $<5\%$; repeated-run CV, prompt spread, trace CV, top-1 stability and
leave-one-trace-out Kendall $\tau$ reported; annotation gate $\kappa\geq0.7$.

\section{Results}
\label{sec:results}

\subsection{The gate blocked our own headline claim}
\label{sec:repro}

Across 3 designs $\times$ 3 traces $\times$ 5 repeats (45 runs, on a second physical
host) the loop reports cross-seed CV $\mathbf{78.16\%}$ against the 5\% threshold,
verdict \textsc{Non-Reproducible}, publish gate \textsc{Blocked}. Repeated-run CV
is $\mathbf{0.0000\%}$: no cell varies across its five runs. The simulator is
deterministic, and determinism is not reproducibility.

The replication is exact on measurement and total on artifact. Cycles, IPC and
instruction counts match the earlier run on all nine cells, yet \textbf{0 of 9}
cells share a delivered binary digest---a rebuild on another host produces
byte-different binaries while the simulated measurement stays bit-identical. A
binary digest therefore evidences that a distinct build was delivered, not design
identity, and a replication gate that demanded digest equality across hosts would
reject a faithful reproduction.

The seed axis explains the gap. \texttt{s1} and \texttt{s3} differ only in the
struct name and two lines of continuation indentation, yet each carries a
different source, design and binary digest while all three traces return
bit-identical cycles. \texttt{s2} keeps a fill history, is 10.6\% faster than the
no-op reference on BFSCC, and reproduces the no-op cycle count exactly on
imagick. The seed moved the artifact and not the design, and nullity is a
per-trace property---our cell-level checker conflates the two, which we record as
a protocol defect.

\subsection{Trace choice reorders the candidates}
\label{sec:trace}

Trace CV is $163.33\%$, top-1 stability $0.667$, mean Kendall $\tau=0.556$: the
ranking is not stable under the trace subset that produced it. The
no-op/next-line control pair separates by 23.15\% on BFSCC but only 0.42\% on
fotonik3d, so a ranking that moves only on fotonik3d is weak evidence and the
grid must be read per trace, not averaged.

\subsection{Independent annotators, and where they agree and are wrong}
\label{sec:audit}

On the 10 specification cases the two models give Cohen's
$\kappa=\mathbf{0.859}$ (0.900 agreement, verdict accuracy 10/10 for both,
error-class exactness 7/10 and 8/10). Widening to all 36 pairs of the nine
factorial candidates, built from real generated C++ rather than dictionary diffs,
gives $\kappa=\mathbf{0.7235}$ overall and $\kappa=\mathbf{1.0}$ on the verdict
axis alone: across 36 real design pairs the annotators never disagree about whether
two designs are the same. On the four measurement-grounded cases $\kappa$ falls to
$\mathbf{0.667}$, below our own 0.7 gate, so that subset is judged red. The same
run showed our calibration set is partly unidentifiable: two cases carry expected
labels that cannot be derived from the payload the annotator sees.

Read with \S\ref{sec:escape}, the high verdict agreement is the warning, not the
reassurance: $\kappa$ measures correlation between annotators, not correctness
against measurement, and $\kappa=1.0$ is exactly what a shared blind spot looks
like from the inside.

\subsection{A nullity escape both auditors missed}
\label{sec:escape}

Compile-and-run is not evidence of a design. Against a cold no-op reference
measuring 1{,}138{,}748 cycles, two \emph{distinct} binaries---a generated stride
prefetcher and a repaired aggressive-offset candidate---return exactly
1{,}138{,}748, while every genuine prefetcher differs (1{,}129{,}110 /
1{,}129{,}706 / 1{,}132{,}568) and the next-line control returns 1{,}129{,}305.
Two of 17 screened designs therefore compile, execute, emit metrics and do
nothing; one is not a lazy stub but a plausible stride prefetcher whose issue path
never fires. Screening the factorial separately added a third:
\texttt{gen\_aggressive\_offset\_s1} also returns 1{,}138{,}748. Three nullities in
26 generated designs---any verifier accepting ``builds, runs, produces numbers''
passes all three.

Both independent annotators classified this case
\texttt{not\_equivalent}/\textbf{E4}; measurement says \texttt{equivalent}. They
agree with each other and disagree with the simulator---a correlated failure, not
independent noise. E0--E4 also has no slot for ``claims to work, measurably does
nothing'': it audits pairwise specification difference, whereas the escape is a
claim-to-measurement gap. What catches it is the nullity check, not the taxonomy.
Reading a candidate is a poor proxy for running it, and more textual auditors buy
agreement rather than independence when they share a failure mode.

\textbf{Artifact.} A harness that only ever returns \textsc{Pass} cannot be
distinguished from one that is not looking, so the release ships the blocked
scorecard, raw cells and digests: loop, cases, generators, gate and
\texttt{scripts/independent\_audit.py} as CHIA-compatible blocks (BSD-3-Clause),
\url{https://github.com/ListenJ/chia-repo-audit}. Reproduce with
\texttt{python3 chia\_loop/loops/audit\_repro.py --version 6 --config
.tmp/cfg/grid.json --backend champsim\_node}.

\section{Limitations}
\textbf{Prompt sensitivity is unmeasured}, not zero: the reported grid held one
prompt constant; the $3{\times}3$ factorial compiled only 6 of 9 candidates, so its
largest complete prompt-by-seed rectangle is 3 prompts at one seed.
\textbf{Repeats:} $0.0000\%$ is $N=5$ per cell (45 runs), but it establishes only
that execution is deterministic; it says nothing about generation variance, which
is the axis that fails. \textbf{Annotators:} both models come
from one provider, so we claim model-model, not cross-family, independence; the
36-pair $\kappa$ rests on heuristic structural labels and only the 4-case subset has
a measurement-grounded label. \textbf{Checker:} the cell-level nullity rule conflates
per-trace with global nullity. \textbf{Provenance:} \texttt{raw.json} records
HEAD at write time, not stage entry. \textbf{Scope:} one simulator, one design
family, three traces; no RTL flow and no gem5 result is claimed.

\section{Conclusion}
We released an audit loop that separates four variance sources, gates publication
on measurement \emph{and} annotation, and keeps its evidence. Against the
official CHIA ChampSim image it blocked its own reproducibility claim at
$78.16\%$ cross-seed CV, showed seeds moving artifacts without moving designs,
showed trace choice reordering candidates ($\tau=0.556$), and showed two
independent language-model auditors agreeing and both wrong on a measured
simulator escape. The instrument and the negative verdicts are the contribution.
