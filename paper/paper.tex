\begin{abstract}
As LLM agents increasingly generate RTL and make microarchitectural decisions,
the community lacks a verifiable benchmark for measuring whether such outputs
are correct and whether their performance claims generalize. We present an
\emph{agentic audit loop} built on the CHIA framework that applies a
double-blind annotation protocol—adapted from proven semantic-equivalence
evaluation ($\kappa{=}0.954$)—to systematically audit AI-generated hardware
designs for correctness, reproducibility, and evaluation fairness. Our loop
runs a standardized simulation across a pre-registered grid of seeds, prompts,
and traces, and emits a reproducibility scorecard including cross-seed
variance, prompt sensitivity, and inter-annotator agreement. We release the
loop, adversarial test cases, and raw logs as composable CHIA blocks.
\end{abstract}

\section{Introduction}
\label{sec:intro}

The Architecture 2.0 ecosystem—ArchAgent, CHIA~\cite{chia}, QuArch,
HLS-Eval—is expanding rapidly: LLM agents now generate RTL, discover cache
replacement policies, and make microarchitectural choices via simulation.
Yet \emph{no existing work systematically measures whether such outputs are
correct or reproducible}.

This gap is alarming given the 2026 benchmark-integrity crisis in the
software domain: the Meerkat audit~\cite{meerkat} found that all top-three
Terminal-Bench~2 submissions \emph{cheated} via harness-level vulnerabilities;
OpenAI deprecated SWE-bench Verified and retracted SWE-bench
Pro~\cite{reprocrisis}; and a systematic review of 168 benchmarks found
$>25.7\%$ have critical defects~\cite{autobench}. If software-side agent
evaluation is this fragile, \emph{hardware-side} agent outputs face at least
as severe reproducibility risks—yet no audit infrastructure exists.

We address this with an agentic audit loop (Figure~\ref{fig:loop}) that
adapts a proven double-blind annotation protocol ($\kappa{=}0.954$,
$\text{N}{=}100$) from semantic-equivalence evaluation to the hardware
design domain. The loop is creative: it is an \emph{agentic loop that audits
other agentic loops}, turning the hackathon's ``agentic architecture'' theme
into a measurable, publishable audit of agent trustworthiness.

\subsection{Stage 1: Prepare}
Pins the environment (git SHA, Python version, tool versions) as a
reproducibility anchor. Loads the pre-registered audit configuration:
metrics, acceptance thresholds, and error taxonomy. \textbf{All thresholds
are frozen before running} (pre-registration), preventing post-hoc
rationalization—a practice directly motivated by the contamination
literature~\cite{contamination}.

\subsection{Stage 2: Run}
Executes a simulation grid across $|\text{seeds}| \times |\text{prompts}|
\times |\text{traces}|$ cells, each repeated $n$ times. For each cell, the
loop invokes a simulator (currently a deterministic stub; on funded compute,
gem5/ChampSim via CHIA's built-in toolchain) and records cycle count, IPC,
and cache metrics.

\subsection{Stage 3: Double-Blind Audit}
\label{sec:dblind}

This is the core novelty. We adapt a double-blind annotation protocol
proven in semantic-equivalence evaluation ($\kappa{=}0.954$, 100 examples,
20\% re-audit sampling) to the hardware domain:

\vspace{-0.5em}

\begin{tabular}{cl}
\toprule
\textbf{Class} & \textbf{Description} \\
\midrule
E0 & Equivalent (correct design) \\
E1 & Parameter mislink (wrong value) \\
E2 & Direction error (e.g., LRU$\leftrightarrow$MRU) \\
E3 & Missing component \\
E4 & Added spurious component \\
\bottomrule
\end{tabular}
\vspace{0.3em}
\caption{Error taxonomy adapted from semantic-equivalence E1--E4.}
\label{tab:errors}
\end{table}

Two independent ``auditor agents'' (A, B) evaluate each candidate design
against its reference specification, classifying errors per Table~\ref{tab:errors}.
Disagreements are resolved by an arbitration agent. Inter-annotator
agreement is measured by Cohen's $\kappa$ (gate: $\kappa \geq 0.7$).
A 20\% re-audit sample detects gold-drift.

\subsection{Stage 4: Act}
Emits a reproducibility scorecard: strict/lenient equivalence rates, $\kappa$,
error-class distribution, cross-seed CV, prompt sensitivity, trace-subset
sensitivity, and a \emph{publish gate} (BLOCKED if $\kappa < 0.7$ or if
adversarial cases are not all detected). Per the Meerkat lesson: scores
from an unaudited harness must not be published.

\section{Experimental Setup}
\label{sec:setup}

\textbf{Framework:} CHIA (BSD-3-Clause) with built-in Chipyard, gem5,
ChampSim, Verilator, Spike. \\
\textbf{Pre-registered metrics:} cross-seed CV $< 5\%$ = reproducible;
prompt sensitivity = cycle-count spread ratio; trace-subset CV. \\
\textbf{Adversarial cases:} 5 pre-planted known-bad designs (E1--E4 $+$ a
``always-passes'' weak-verifier trap) to test whether the audit catches them. \\
\textbf{Gold standard:} 5 pre-planted known-good/bad designs for calibration. \\
\textbf{Compute:} short-term funded GCP/Gemini credits (Sep 21--23).

\section{Results}
\label{sec:results}

\textbf{Stub validation.} On the deterministic stub, the loop correctly:
\begin{itemize}\setlength{\itemsep}{0pt}
\item Detects injected cross-seed noise (CV $= 3.56\%$, under the 5\% threshold $\rightarrow$ \textsc{Reproducible});
\item Flags the prompt-sensitivity dimension (CoT/adversarial variants shift cycle counts by 6.9--7.1\%);
\item Blocks the publish gate when adversarial weak-verifier cases are not rejected.
\end{itemize}

\textbf{Key finding (stub).} The optimism gap between \texttt{pass@$k$}
(any-of-$k$ succeeds) and \texttt{pass\^{}$k$} (all-of-$k$ succeeds) is
\textbf{170\%} at $k{=}3$: macro \texttt{pass@3} $= 0.925$ vs.\ macro
\texttt{pass\^{}3} $= 0.25$. This demonstrates that the standard ``best-of-$n$''
reporting convention \emph{systematically overstates agent reliability by
$>2\times$}, a finding consistent with~\cite{passk}.

will be filled before the Sep~24 submission.

\section{Discussion}
\label{sec:discuss}

\textbf{Why double-blind?} Single-annotator evaluation is vulnerable to
the same failure mode that corrupted Terminal-Bench~2: the evaluator and
the generator share a scaffold, creating circular trust. Double-blind
annotation with $\kappa$ quantification breaks this circularity.

\textbf{Composability.} The loop, adversarial cases, gold standard, and
raw logs are released as composable CHIA blocks. Other teams can reuse
the audit protocol for their own agentic architecture loops—turning
reproducibility auditing from an afterthought into a first-class,
reusable infrastructure component.

\textbf{Limitations.} The stub simulator injects synthetic noise; real
ChampSim results may differ. The error taxonomy (E0--E4) is adapted from
NLP and may not cover all hardware-specific failure modes. Cohen's
$\kappa$ on design correctness is a first—no prior work establishes a
baseline.

\section{Conclusion}
We present the first agentic loop that audits the reproducibility and
correctness of \emph{other} agentic architecture loops, using a proven
double-blind protocol. The loop is composable, the methodology is
pre-registered, and early results show a $170\%$ optimism gap in standard
agent-reliability reporting. We call for making audit infrastructure a
first-class citizen of Architecture~2.0.
