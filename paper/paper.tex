\begin{abstract}
Agents already \emph{discover and exploit loopholes in microarchitectural
simulators}~\cite{archagent}, so we measure evaluation validity rather than design
discovery. We release a CHIA audit loop that separates four variance sources an
aggregate score hides---repeated-run, generation-seed, prompt and
trace---gating publication on both a pre-registered threshold and a double-blind
annotation layer scored by same-provider models and by a third, architecturally
different one. Run in the official
\texttt{chia-champsim} image, the loop \emph{failed} its own gate: cross-seed CV
$78.16\%$ against a $5\%$ threshold within one generated series, while repeated-run
CV is $0.0000\%$ over 45
runs, so the publish gate reads \textsc{Blocked}. Two candidates differing only in
a struct name and indentation carry distinct source, design and binary digests yet
bit-identical cycles on all three traces: the seed moved the artifact, not the
design. Ranking is unstable (top-1 $0.667$, Kendall $\tau=0.556$) and prompt
response reaches $249.18\%$. Annotation gives $\kappa=0.859$ on specification diffs
and $0.636$ on real generated C++, below our own 0.7 gate on both external sets;
there both models are correct on all 33 labellable pairs and share no error. On the six
measurement-grounded pairs they never disagree yet each is right on only 3 of 6, and the
three they miss together are all measured simulator escapes. Auditing that
$\kappa$ found the defect inside it: our own label generator read \texttt{\#include}
angle brackets as comparison operators and mislabelled three rename-only pairs, so
the annotators we were scoring were correct and the ground truth was not. We report
the negatives and the self-repairs instead of moving the thresholds.
\end{abstract}

\section{Introduction}
\label{sec:intro}

Architecture 2.0 pipelines (ArchAgent~\cite{archagent}, CHIA~\cite{chia},
QuArch) let agents propose and evaluate designs with no human in the loop. The
risk is not unclaimed: ArchAgent reports its pipeline discovered and exploited a
loophole in a popular microarchitectural simulator, inflating reported
performance without changing hardware logic~\cite{archagent}. Software-side
evaluation shows the same fragility---the top three Terminal-Bench~2 submissions
were all found guilty of cheating via harness-level tricks~\cite{meerkat}, OpenAI
stopped evaluating on SWE-bench Verified and its audit of SWE-bench Pro found
roughly $30\%$ of that suite's tasks broken~\cite{swebench}, and an automated audit
of 168 agent benchmarks flags issues in over $25.7\%$ of the evaluated
\emph{tasks}~\cite{autobench}.

What is missing is an instrument, not another warning: a loop that runs against a
real simulator, separates the variance sources an aggregate score hides, and
refuses to publish when the separation fails. We contribute that loop plus what
it said about us---a \textsc{Blocked} verdict on our own headline claim
(\S\ref{sec:repro}), evidence that generation seeds move artifacts without
moving designs, trace-dependent reordering (\S\ref{sec:trace}) and prompt response
at $249.18\%$ (\S\ref{sec:prompt}), a failure mode that text-reading auditors cannot
catch (\S\ref{sec:escape}), and six defects we found in our own automation---a
vacuous gate axis (\S\ref{sec:prompt}), a generated ground truth that was wrong
while the annotators were right (\S\ref{sec:groundtruth}), a nullity rule that could
not tell an inert design from an ineffective one (\S\ref{sec:repro}), a screening file
whose incremental rows cannot be attributed to the module they name, a measurement
attributed to a source that cannot compile (\S\ref{sec:attribution}), and an
escalation signal whose approval score does not separate a local reversible edit from
destroying an instance (\S\ref{sec:gate2}).

\section{The Audit Loop}
\label{sec:loop}

\textbf{Prepare.} Pin git SHA, interpreter and image digest; load the
pre-registered configuration. Thresholds are frozen before any measured cell
exists, which is what makes the \S\ref{sec:results} verdicts binding rather than
negotiable. \textbf{Run.} Execute a
$|\text{seeds}|\times|\text{prompts}|\times|\text{traces}|$ grid, $n$ repeats per
cell, through CHIA's \texttt{ChampSimNode} in the official image, recording the
candidate digest, delivered binary digest and raw simulator JSON per cell.
\textbf{Audit.} Two annotators classify candidate against reference using E0--E4
(Table~\ref{tab:errors}). The payload is built from an allowlist of \texttt{id},
\texttt{design}, \texttt{reference}; the script refuses to run if any expected
label survives. We report the deterministic in-loop self-test and the
independent-model layer separately and never merge them. \textbf{Act.} Emit the
scorecard and gate: \texttt{publishable} requires reproducibility \textsc{Pass}
\emph{and} audit \textsc{Pass}. A nullity check compares each candidate with a
no-op reference measured on the same trace and instruction budget.

\subsection{The gate blocked our own headline claim}
\label{sec:repro}

Across 3 designs $\times$ 3 traces $\times$ 5 repeats (45 runs, on a second physical
host) the loop reports cross-seed CV $\mathbf{78.16\%}$ against the 5\% threshold,
verdict \textsc{Non-Reproducible}, publish gate \textsc{Blocked}. Repeated-run CV
is $\mathbf{0.0000\%}$: no cell varies across its five runs. The simulator is
deterministic, and determinism is not reproducibility (Fig.~\ref{fig:decomp}a).

The replication is exact on measurement and total on artifact. Cycles, IPC and
instruction counts match the earlier run on all nine cells, yet \textbf{0 of 9}
cells share a delivered binary digest---a rebuild on another host produces
byte-different binaries while the simulated measurement stays bit-identical. A
binary digest therefore evidences that a distinct build was delivered, not design
identity, and a replication gate that demanded digest equality across hosts would
reject a faithful reproduction. The converse failure is present in our own screening
data and is easier to miss: module \emph{names} are not design identifiers either.
\texttt{gen\_fill\_only\_conservative\_s2} occurs in both screening batches under
different delivered binaries (digests \texttt{ace3ea88\ldots} and \texttt{b83f003a\ldots})
and measures $1{,}132{,}568$ in one and $1{,}129{,}110$ in the other. Any join keyed
on the module name silently discards one of those measurements---which is exactly what
an earlier version of Fig.~\ref{fig:decomp} did before we keyed it on the digest.

The seed axis explains the gap. \texttt{s1} and \texttt{s3} differ only in the
struct name and two lines of continuation indentation, yet each carries a
different source, design and binary digest while all three traces return
bit-identical cycles. \texttt{s2} keeps a fill history, is 10.6\% faster than the
no-op reference on BFSCC, and reproduces the no-op cycle count exactly on
imagick. The seed moved the artifact and not the design, and nullity is a per-trace
property: our evidence checker used to report a design that is inert on one workload
under the same flag as one that is inert everywhere, so it now separates
\texttt{null\_on\_every\_measured\_trace} (a null design) from a note recording
trace-dependent inertness, which is a normal result and not a gate failure.

That $78.16\%$ is scoped to one generated series, and a second series says why.
A replication of the same prompt at seeds $\{2,3\}$ drawn from a \emph{different}
candidate directory measures cross-seed CV $\mathbf{0.0000\%}$: those two seeds
reproduce each other bit-exactly on all three traces. The two directories hold
different programs under the same module name---\texttt{gen\_fill\_only\_conservative\_s2}
is 1{,}210 source characters in one and 1{,}107 in the other, and its BFSCC cycle
count is 6{,}420{,}195 versus 95{,}624{,}440---so the $15\times$ gap between the two
grids is an input difference, not a measurement disagreement, and the two
\texttt{raw.json} files record distinct \texttt{candidate\_sha256} values that are
what made this checkable. A seed label is not a design identifier across series, and
the seed effect reported here is a property of one series rather than of agentic
generation in general.

\subsection{Trace choice reorders the candidates}
\label{sec:trace}

Trace CV is $163.33\%$, top-1 stability $0.667$, mean Kendall $\tau=0.556$: the
ranking is not stable under the trace subset that produced it. The
no-op/next-line control pair separates by 23.15\% on BFSCC but only 0.42\% on
fotonik3d, so a ranking that moves only on fotonik3d is weak evidence and the
grid must be read per trace, not averaged.

\subsection{Prompt sensitivity is 249\%, and the gate could not see it}
\label{sec:prompt}

A separate $1\,\text{seed}\times3\,\text{prompt}$ grid over three traces gives
maximum prompt spread $\mathbf{249.18\%}$, computed as
$(\max-\min)/\text{mean}$; the
spread is almost entirely one trace. The same grid carries a second, worse story.
Because it holds the seed constant, cross-seed CV was computed over a single value,
and our variance helper returns $0.0$ for fewer than two samples---so the gate
printed $\text{cross-seed CV}=0.0000\%$, watched it satisfy the $<5\%$ threshold,
and returned \textsc{Reproducible}/\textsc{Publishable}. \textbf{An axis that never
varied cannot fail a threshold on that axis}, and our gate had no way to know the
difference between a measured $0\%$ and an unmeasured one.

The fix counts factor levels: an axis with fewer than two levels is
\emph{unexercised}, can never satisfy the gate, and is named in
\texttt{publish\_blockers} as \texttt{axis\_not\_exercised:seed}. Every retained
\texttt{raw.json} was then rescored without re-running the simulator
(\texttt{scripts/rescore\_grid.py}), and the scorecard above now prints its axis
levels next to its verdict. The rescored verdict is
\textsc{Non-Reproducible}/\textsc{Blocked}.

\subsection{Independent annotators, and where they agree and are wrong}
\label{sec:audit}

On the 10 specification cases the two models give Cohen's
$\kappa=\mathbf{0.859}$ (0.900 agreement, verdict accuracy 10/10 for both,
error-class exactness 7/10 and 8/10). Widening to pairs of the nine
factorial candidates, built from real generated C++ rather than dictionary diffs,
initially gave $\kappa=0.7235$ over 36 pairs with $\kappa=\mathbf{1.0}$ on the
verdict axis. \S\ref{sec:groundtruth} shows why that number cannot be quoted: the
gold labels for that set were themselves generated, and three of its pairs were
mislabeled by our own structural rule. After relabeling, \textbf{33 of 36} pairs
carry a derivable verdict, both annotators are correct on \textbf{all 33}
(verdict accuracy $\mathbf{1.0}$ each), they never disagree ($\kappa=1.0$ on
verdict), and combined-label $\kappa$ falls to $\mathbf{0.636}$. That is now
\emph{below} our own 0.7 gate too, so both external sets are red, not just the
measured one: the pre-correction 0.7235 was the only value that passed, and it
passed on labels that had to be withdrawn. On the
\textbf{six} measurement-grounded cases---three real nullity escapes, added to the
original four after we found the escape case had cited a source that cannot
compile---the two models never disagree once ($\kappa=1.0$ on verdict,
0 disagreements), and each is right on only 3 of 6 (verdict accuracy
$\mathbf{0.5}$); combined-label $\kappa$ is $\mathbf{0.455}$. The three cases they
miss together are \emph{exactly} the three escapes, and no escape is missed by only
one of them.

One caveat we have to carry rather than resolve: \textbf{all 33 labellable gold
labels in that set are \texttt{not\_equivalent}}---no pair of generated candidates
was ever labelled equivalent---so a rater that always answers
\texttt{not\_equivalent} would also reach $\kappa=1.0$ on the verdict axis, and our
$\kappa$ helper returns exactly 1.0 by convention whenever the marginals are
degenerate. The verdict-only row is therefore \emph{not} evidence of reliability on
this set; the combined-label 0.636 is the statistic that means something. On the
specification and measured sets, where both classes occur, verdict $\kappa$ is
non-degenerate.

Read with \S\ref{sec:escape}, the high verdict agreement is still the warning, not
the reassurance: $\kappa$ measures correlation between annotators, not correctness
against measurement, and $\kappa=1.0$ is what a shared blind spot looks like from
the inside---and also what a shared \emph{correct} reading looks like when the
ground truth is the defective party. Agreement statistics cannot tell those two
apart, which is the point of \S\ref{sec:groundtruth}.

\subsection{A nullity escape both auditors missed}
\label{sec:escape}

Compile-and-run is not evidence of a design. Against a cold no-op reference
(Fig.~\ref{fig:decomp}b)
measuring 1{,}138{,}748 cycles, two \emph{distinct} binaries---a generated stride
prefetcher and a repaired aggressive-offset candidate---return exactly
1{,}138{,}748, while every genuine prefetcher differs (1{,}129{,}110 /
1{,}129{,}706 / 1{,}132{,}568) and the next-line control returns 1{,}129{,}305,
from a cold-build row carrying its own binary digest; the control pair's distinct
binaries are recorded separately in \texttt{reference\_designs}.\footnote{The same
screening file also carries three \emph{incremental} rows that name three different
modules while recording one shared binary digest and one shared cycle count. Those
rows are not attributable to a design and none of our claims rest on them; the
escape case cites that file only as context.}
Two of the 13 distinct designs in that screening batch therefore compile, execute,
emit metrics and do nothing; one is not a lazy stub but a plausible stride
prefetcher whose issue path never fires. Screening the factorial separately (9
distinct candidates, 6 compiling) added a third:
\texttt{gen\_aggressive\_offset\_s1} also returns 1{,}138{,}748. Three nullities
across two screening batches---any verifier accepting ``builds, runs, produces
numbers'' passes all three.

Both independent annotators classified this case
\texttt{not\_equivalent}/\textbf{E4}; measurement says \texttt{equivalent}. They
agree with each other and disagree with the simulator---and this is no longer a single
observation. Three of the six measurement-grounded cases are nullity escapes, drawn
from two screening batches and three distinct delivered binaries, and both raters miss
\textbf{all three} in the same direction while missing none of the three non-escape
cases. That is a systematic blind spot rather than independent noise, though the
denominator is still six and we do not claim more than that. This
result was re-obtained after we found and fixed an attribution error in the case
itself: the source it embedded was a same-named file that does not compile against
the pinned image, while the measurement came from a second file in another candidate
directory (\S\ref{sec:attribution}). Re-annotating the corrected source leaves the
outcome and the $\kappa=0.455$ unchanged, with both rationales still naming the added
stride mechanism. Nor is the failure an artefact of how the pair is framed: exchanging
which design is labelled candidate and which is reference leaves all twelve verdicts
unchanged ($0/12$ flips, \texttt{scripts/annotation\_role\_swap.py}), so the blind spot is
symmetric rather than a reading of narrative direction. E0--E4
also has no slot for ``claims to work, measurably does
nothing'': it audits pairwise specification difference, whereas the escape is a
claim-to-measurement gap. What catches it is the nullity check, not the taxonomy.
Reading a candidate is a poor proxy for running it, and more textual auditors buy
agreement rather than independence when they share a failure mode.

\subsection{Ground truth is generated too}
\label{sec:groundtruth}

Three of the defects in this paper---\S\ref{sec:prompt}, this section and
\S\ref{sec:gate2}---are one failure mode seen three times: a quantity whose name claims
a measurement stops referring to the thing measured, and still returns a passing value.

Every number in \S\ref{sec:audit} is scored against a label we did not hand-write.
The 36 semantic pairs were labelled by a structural rule: compare class members,
numeric literals, and comparison operators between the two sources. That rule read
\texttt{\#include} \texttt{<vector>} as two comparison operators. Three candidate
pairs whose designs differ in nothing but local variable names, comments, header
count and an explicit \texttt{this->} were therefore labelled
\texttt{not\_equivalent}/\textbf{E2}, ``direction error''. Both generative
annotators called all three \texttt{equivalent}, with rationales naming exactly
the cosmetic differences involved. \textbf{The annotators were right and our ground
truth was wrong}, and the artifact had been reporting their three correct answers
as three shared errors.

Two things follow. First, the fix is not to re-query the models: their replies are
retained, so a label defect is rescored, not re-run
(\texttt{scripts/relabel\_semantic\_cases.py}), and is now locked by four regression
tests. Second, \texttt{classify()} had a second, quieter hole: it returned
\texttt{not\_equivalent} whenever normalized text differed at all, so a pair with no
shared trace measurement and no derivable error class was asserted to be a
behavioral difference. It now abstains with an explicit \texttt{unlabellable}
verdict---\textbf{3 of 36} pairs land there---and defers to measurement whenever
cycles agree on shared traces, which is the rule that earns the escape case its
\texttt{equivalent} label in the first place. An \texttt{unlabellable} pair is
scored as no evidence at all rather than as a wrong answer.

\subsection{A measurement attributed to a file that cannot produce it}
\label{sec:attribution}

Building a positive control for the nullity check, the grid path rejected
\texttt{gen\_default\_s0} with \texttt{invalid static\_cast from champsim::address to
int64\_t}---and the escape case's embedded source is byte-for-byte that rejected file,
matching its own declared hash. The screening log holds two rows for that module name:
a failed build with the identical error, then a successful cold build measuring
1{,}138{,}748. The runner had swept four candidate directories holding 5, 6, 3 and 3
files, which map in sorted order onto the 17 screening rows and place the successful row
inside the second directory: the measurement belongs to a \emph{different} file that
happens to share the name.

Screening rows record a module name and a delivered-binary digest but \textbf{no source
digest}, so ``which file produced this measurement'' is unanswerable from the artifact
after the fact---the same object this paper audits, reached from the other side. We now
carry \texttt{scripts/audit\_case\_attribution.py}, which re-derives every embedded
source hash against every candidate file on disk (80 assertions, all self-consistent,
63 name collisions across 11 module names: the reason no internal check could find this),
and the escape case records the correction with both hashes.

\subsection{A third substrate buys agreement, not independence}
\label{sec:substrate}

Both generative annotators come from one provider, so we added an architecturally
distinct rater: a 421M ModernBERT \emph{discriminative} head, non-autoregressive,
which cannot generate the rationale an audit prompt asks for. Run on the same three
case sets as a third annotator, it is accurate on 0.5 of the 10 specification cases
and 0.667 of the 6 measurement-grounded cases, and on \textbf{0 of 33} real generated
pairs---it answers \texttt{equivalent} on 35 of 36 while every labellable gold label
in that set is \texttt{not\_equivalent}. Its single non-default answer falls on one
of the three pairs whose label \S\ref{sec:groundtruth} had to withdraw, so even that
hit is unscoreable. Its agreement with the two generative raters is
$\kappa=0.138$, $\mathbf{-0.364}$ and $-0.057$ across the three sets: on two of
three sets it is anti-correlated with them, not merely uninformative.

On the escape case itself it answers \texttt{equivalent}---\emph{correct}, matching
measurement where both generative raters failed---at a top-1 minus top-2 margin of
\textbf{0.010}. It is right for no reason a verifier can detect. A scoring rule that
rewards agreement with measurement would bank that hit and never see that the same
default loses 33 of 33 elsewhere. Changing substrate does not buy independence:
independence is a property of the \emph{evidence channel}, and only the simulator
provides one here.

\subsection{An approval score that cannot separate the safe action from the destructive one}
\label{sec:gate2}

We ran the loop's own decisions through a local discriminative decision head under a
gate that escalated whenever its \texttt{needs-approval} score exceeded $0.5$. It
escalated \textbf{6 of 6}, including a local, reversible rewrite of a committed
scorecard---which scored \emph{higher} ($0.895$) than an actual push to the public
artifact ($0.848$). To test rather than assume, we built ten scenarios of known
blast radius (local reversible; pre-authorised spend; outside write; irreversible
destroy) and measured the score against the tier:
Spearman $\rho=+0.406$ over $n=10$, with
$\min(\text{tier }3)-\max(\text{tier }0)=-0.169$, i.e.\ \emph{no} threshold separates
the safest action from the most destructive. Editing a conference submission scored
$0.126$, below the safe local rewrite at $0.160$.

A rule built on that score is not conservative, it is constant: it escalates
everything, so the automation delivers nothing and the human sees no more signal than
before. The fix removes the model from that judgement---blast radius is declared per
\emph{option} in code and the model only chooses among options, with the score kept as
an advisory cross-check (it now agrees with the register on 3 of 4 decisions). This
also exposed a granularity bug: the register had been attached to the whole question,
so an option meaning \emph{leave the instances running} was reported as irreversible.
Re-running the same six decisions under the register moves the automatic share from
0/6 to 2/6, and every remaining escalation is correctly motivated: two outside writes,
two margins below 0.15. The ladder, the gate and the recorded verdicts ship in
\texttt{decision\_chain/}.

distinguished from one that is not looking, so the release ships the blocked

reachable. Every number quoted in this paper
is re-derived from the committed artifacts by

\section{What this should change}
\label{sec:changes}

Each rule below is stated as a check an author can run, because every one of them was
violated by us and caught by reading primary evidence rather than by a green gate.
\textbf{(1) Report factor levels next to every variance statistic.} A spread computed
over fewer than two levels of its own axis must be emitted as \emph{unexercised}, never
as a value that can satisfy a threshold. \textbf{(2) Treat labels as generated
artifacts.} Where a verdict can be grounded in measurement, ground it; where it cannot,
abstain rather than infer, and fuzz structural labelers against non-design syntax such
as preprocessor lines and comments. \textbf{(3) Key identity on the delivered
digest, and report the label marginal with every agreement statistic.} $\kappa$ without
the class distribution is uninterpretable, and $\kappa=1.0$ on a single-class set means
nothing. \textbf{(4) Do not let a learned score decide what needs human approval}
unless it is shown to separate the safe action from the destructive one; a rule that
escalates everything automates nothing. \textbf{(5) Make a nullity check a gate, not a
diagnostic.} ``Compiles, runs, produces numbers'' passed three designs that do nothing;
any verifier weaker than a comparison against a no-op reference will pass them too.
\textbf{(6) Record a source digest beside every measurement.} A delivered-binary digest
says a build happened, not which source produced it; a module name says even less. Our
screening rows carried both and still let a cycle count be attributed to a file that
cannot compile, because the one thing missing was the hash of the input.

\section{Limitations}
\textbf{Axes are measured separately.} Prompt spread comes from a
$1\times3$ grid and cross-seed CV from a $3\times1$ one; no reported cell yet varies
seed and prompt simultaneously, so we cannot say whether the $249.18\%$ prompt
response and the $78.16\%$ seed response compose or interfere.
\textbf{Repeats:} $0.0000\%$ is $N=5$ per cell (45 runs), but it establishes only
that execution is deterministic; it says nothing about generation variance, which
is the axis that fails. \textbf{Labels:} the 33-pair $\kappa$ rests on structural
labels that survive our own header-parsing defect only because we could re-derive
them; only the 4-case set has a measurement-grounded label, and the three shared errors are the three escapes, so the
failure is systematic on this set rather than a single coincidence. That set carries no \texttt{equivalent} gold case at all, which is
why its verdict-axis agreement is reported as degenerate rather than as reliability.
\textbf{One series per axis.} Each grid draws candidates from a single directory, and
the same module name denotes different programs across directories, so no number here
is a cross-series estimate: the $78.16\%$ and $0.0000\%$ cross-seed CVs are both
correct and describe different generated series.
\textbf{Annotators:} both generative models come from one
provider, and \S\ref{sec:substrate} shows that the architecturally different rater
we could reach is worse than independent rather than better.
\textbf{Annotation validity:} the raters are large models, and we tested one threat and
not the other. Exchanging candidate and reference leaves every verdict unchanged
($0/8$), so the layer is not reading narrative direction; but we did not test whether
their verdicts are inflated by exposure to similar C++ prefetcher code in training,
which systematic reviews of contamination detection treat as the dominant
risk~\cite{contamination}. We name that as uncontrolled rather than claim to have ruled
it out, and it bears most on the 33-pair result since those inputs are real generated
source. \textbf{Checker:} the
cell-level nullity rule conflated per-trace with global nullity until this revision;
the split is locked by four tests, but the replicated grid contains no design that is
inert on \emph{every} trace, so the stricter branch has a synthetic positive control
and no real one.
\textbf{Provenance:} \texttt{raw.json} records HEAD at write time, not stage entry.
One supporting screening file carries a binary attribution defect: three of its
incremental rows name three different modules yet record one \texttt{binary\_sha256}
and one cycle count, so those rows cannot evidence which design was measured. Every
nullity cited here comes from a cold-build row whose digest differs per design, and
the escape case records the unattributable file only as corroborating context.
\textbf{Scope:} one simulator, one design
family, three traces; no RTL flow and no gem5 result is claimed.

\section{Conclusion}
We released an audit loop that separates four variance sources, gates publication
on measurement \emph{and} annotation, and keeps its evidence. Against the
official CHIA ChampSim image it blocked its own reproducibility claim at
$78.16\%$ cross-seed CV, showed seeds moving artifacts without moving designs,
showed trace choice reordering candidates ($\tau=0.556$) and prompt response at
$249.18\%$, and showed two same-provider language-model auditors agreeing and both
wrong on a measured simulator escape---a result that survived re-annotation after we
found the case had cited a source that cannot compile. It also caught six silent defects
in our own automation---a gate that passed an unexercised axis, a labeler that read
\texttt{\#include} brackets as comparison operators, a nullity rule that could not tell
an inert design from an ineffective one, a screening file whose incremental rows cannot
be attributed to the module they name, a measurement attributed to a file that cannot
produce it, and an escalation rule built on an approval score we then measured not to
separate safe from destructive.
The instrument, the negative verdicts, the six protocol rules we would ask of any
such loop (\S\ref{sec:changes}) and the self-reports are the contribution.
