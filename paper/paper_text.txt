Does Agentic Architecture Discovery Reproduce? An Audit Gate
That Blocked Its Own Headline Result
Anonymous Author(s)
Abstract
Agents alreadydiscover and exploit loopholes in microarchitectural
simulators[ 1], so we measure evaluation validity rather than design
discovery. We release a CHIA audit loop that separates four vari-
ance sources an aggregate score hides (repeated-run, generation-
seed, prompt and trace) and gates publication on a pre-registered
threshold plus a double-blind annotation layer. Run in the official
chia-champsim image, the loopfailedits own gate: cross-seed CV
78.16%against a5%threshold within one generated series, while
repeated-run CV is0 .0000%over 45 runs, so the publish gate reads
Blocked. Two candidates differing only in a struct name carry dis-
tinct source, design and binary digests yet bit-identical cycles: the
seed moved the artifact, not the design. Annotation gives 𝜅= 0.859
on specification diffs and0 .636on real generated C++, both below
our own 0.7 gate; on six measurement-grounded pairs two same-
provider models never disagree yet each is right on only 3 of 6,
and a second provider reproduces those three misses, all of them
simulator escapes. Auditing that 𝜅 found the defect inside it: our
own label generator read#include angle brackets as comparison
operators and mislabelled three rename-only pairs, so the annota-
tors we were scoring were correct and the ground truth was not.
We report the negatives, ten defects found in our own automation,
and the repairs instead of moving thresholds.
1 Introduction
Architecture 2.0 pipelines (ArchAgent [1], CHIA [2], QuArch) let
agents propose and evaluate designs with no human in the loop, and
the risk is not unclaimed: ArchAgent reports that its own pipeline
found and exploited a loophole in a popular microarchitectural sim-
ulator, inflating reported performance without changing hardware
logic [1]. Software-side evaluation shows the same fragility: the
top three Terminal-Bench 2 submissions were all caught cheating
via harness tricks [3], OpenAI dropped SWE-bench Verified after
an audit found roughly30%of SWE-bench Pro’s tasks broken [ 4],
and an automated audit of 168 agent benchmarks flags over25 .7%
of the evaluatedtasks[5].
What is missing is an instrument, not another warning: a loop
that runs against a real simulator, separates the variance sources an
aggregate score hides, and refuses to publish when that separation
fails. We contribute that loop plus what it said about us: aBlocked
verdict on our own headline claim (§3.1), seeds moving artifacts
without moving designs, trace-dependent reordering (§3.2), prompt
response at249 .18%(§3.3), a failure mode text-reading auditors
cannot catch and a second provider repeats (§3.5), and ten defects in
our own automation (Table 1). Each was found by reading evidence,
none by a green gate.

3 Results
3.1 The gate blocked our own headline claim
Across 3 designs× 3 traces× 5 repeats (45 runs, on a second physical
host) the loop reports cross-seed CV 78.16% against the 5% thresh-
old, verdictNon-Reproducible, publish gateBlocked. Repeated-
run CV is 0.0000%: no cell varies across its five runs. The simulator
is deterministic, and determinism is not reproducibility (the vari-
ance decomposition of Fig. 1 in the full report).
Cycles, IPC and instruction counts match the earlier run on all
nine cells, yet0 of 9cells share a delivered binary digest: a rebuild
on another host produces byte-different binaries while the simu-
lated measurement stays bit-identical. A binary digest therefore
evidences a distinct build, not design identity, and a gate demanding
digest equality across hosts would reject a faithful reproduction.
The converse failure is in our own screening data: modulenames
are not identifiers either. gen_fill_only_conservative_s2 oc-
curs in both batches under different delivered binaries, measuring
1,132,568and1 ,129,110: a join keyed on the name silently drops
one.
The seed axis explains the gap. s1 and s3 differ only in the
struct name and two lines of continuation indentation, yet each
carries a different source, design and binary digest while all three
traces return bit-identical cycles. s2 keeps a fill history, is 10.6%
faster than the no-op reference on BFSCC, and reproduces the no-
op cycle count exactly on imagick. The seed moved the artifact
and not the design, and nullity is a per-trace property, so the ev-
idence checker now separates null_on_every_measured_trace
from trace-dependent inertness.
That78 .16%is scoped to one generated series, and a second series
says why. A replication of the same prompt at seeds {2, 3} from
adifferentcandidate directory measures cross-seed CV 0.0000%,
because the two directories hold different programs under the same
module name (BFSCC cycles 6,420,195 versus 95,624,440). The15×
gap is an input difference, not a measurement disagreement, and
only the distinct candidate_sha256 values made it checkable: a
seed label is not a design identifier across series.
3.2 Trace choice reorders the candidates
Trace CV is163 .33%, top-1 stability0 .667, mean Kendall 𝜏= 0.556:
the ranking is not stable under the trace subset that produced it. The
control pair separates by 23.15% on BFSCC but 0.42% on fotonik3d,
so the grid must be read per trace. And the stability number is
not stable either: a second rectangle,2 seeds× 2 prompts× 3 traces
(12 cells, 36 runs), same harness, same pinned image, same traces,
reports top-1 stability 1.0 and 𝜏=0.778 over four designs. Nothing
in the instrument changed; only the candidate set did. So 𝜏= 0.556
and 𝜏= 0.778are both correct readings of the same code, and “the
ranking is unstable” is a claim about a design set, not about agentic
architecture discovery.
3.3 Prompt sensitivity is 249%, and the gate
could not see it
A separate1 seed× 3 prompt grid over three traces gives maxi-
mum prompt spread 249.18%, computed as(max−min)/mean ; the
spread is almost entirely one trace. The two axes do not mask
each other: the2× 2rectangle measures cross-seed CV 23.50% and
prompt spread 179.67% simultaneously, both far above the5%gate.
The same grid carries a second, worse story. Because it held the
seed constant, cross-seed CV was computed over a single value,
and our variance helper returns0 .0for fewer than two samples, so
the scorecard printed cross-seed CV= 0.0000%, watched it satisfy
the < 5%threshold, and returnedReproducible/Publishable.An
axis that never varied cannot fail a threshold on that axis, and
our gate could not tell a measured0%from an unmeasured one. The
fix counts factor levels: an axis with fewer than two levels isunexer-
cised, can never satisfy the gate, and is named inpublish_blockers
as axis_not_exercised:seed. scripts/rescore_grid.py then
rescored every retainedraw.json without re-running the simula-
tor; the verdict isNon-Reproducible/Blocked.
3.4 Independent annotators, and a shared blind
spot two providers reproduce
On the 10 specification cases the two models give Cohen’s𝜅=0.859
(0.900 agreement; verdict accuracy 10/10, error-code exactness 7/10
and 8/10). Widening to pairs of the nine factorial candidates, built
from real generated C++ rather than dictionary diffs, gave 𝜅=
0.7235over 36 pairs; Table 1 row 2 shows why that cannot be
quoted. After relabeling,33 of 36pairs carry a derivable verdict,
both annotators are correct onall 33, they never disagree ( 𝜅= 1.0
on verdict), and combined-label 𝜅 falls to 0.636. That is below our
own 0.7 gate too, so both external sets are red: 0.7235 was the only
value that passed, and it passed on withdrawn labels. On thesix
measurement-grounded cases the two models do not disagree (0
disagreements), and each is right on only 3 of 6 (verdict accuracy
0.5); combined-label 𝜅 is 0.455. The three cases they miss together
areexactlythe three escapes of §3.5, and no escape is missed by
only one of them.
One caveat we cannot resolve:all 33 labellable gold labels
in that set are not_equivalent, so a constant not_equivalent
rater would also reach 𝜅= 1.0, and our helper returns exactly 1.0
on degenerate marginals. The verdict-only row is thereforenot
evidence of reliability; the 0.636 is. And high verdict agreement is
the warning, not the reassurance: 𝜅 measures correlation between
annotators, not correctness against measurement. 𝜅= 1.0is what a
shared blind spot looks like from the inside, and also what a shared
correctreading looks like when the ground truth is the defective
party.
3.5 A nullity escape both auditors missed, and a
second provider repeats
Compile-and-run is not evidence of a design. Against a cold no-
op reference (the nullity screen of Fig. 1b in the full report) mea-
suring 1,138,748 cycles, twodistinctbinaries (a generated stride
prefetcher and a repaired aggressive-offset candidate) return ex-
actly 1,138,748, while every genuine prefetcher and the next-line
control differ. A separate screening of the factorial added a third:
gen_aggressive_offset_s1. Three nullities across two batches:
any verifier accepting “builds, runs, produces numbers” passes all
three.

Both annotators classified this casenot_equivalent/E4; mea-
surement says equivalent. They agree with each other and dis-
agree with the simulator. Three of the six measured cases are nullity
escapes, from two screening batches and three distinct binaries;
both raters missall threein the same direction and miss none of the
other three. That is a systematic blind spot, not independent noise,
on a denominator of six. Nor is it an artefact of framing: swapping
candidate and reference leaves all twelve verdicts unchanged (0/12
flips,scripts/annotation_role_swap.py). E0–E4 has no slot for
“claims to work, measurably does nothing”: it audits pairwise speci-
fication difference, whereas the escape is a claim-to-measurement
gap. What catches it is the nullity check, not the taxonomy.
That account rests on two raters who share a provider, so we
put the same question to a second provider,Atria-Dawn-Preview
attemperature 0, shown payloads carrying the published raters’
own prompt digests so prompt drift cannot explain any agreement
between them. It reproduces the blind spot rather than breaking
it. On the six measured cases it recovers 3 of 6 verdict labels and 1
of 6 error-code labels, and the three verdicts it misses are exactly
the three escapes, each returned as not_equivalent/E4. On the
36 real-source pairs they agree completely where a label exists:
on the 33 labellable pairs all three reproduce the recorded verdict
(33/33each) and separate only on the error codes, matching the
recorded set on 7, 9 and 6 of those same 33, with 26 of the 27 second-
provider misses strict supersets of it. On the threeunlabellable
pairs every rater answers equivalent: none abstains where the
rubric derives nothing. Agreement aboutwhichcode fired, not
about equivalence, is the scarce quantity. Switching providers buys
coverage of a different failure mode, not freedom from this one.
scripts/rater_rollup.py re-derives every number here from
the per-case labels and refuses the artifact on drift.
3.6 A third substrate buys agreement, not
independence
We also ran an architecturally distinct rater: a 421M ModernBERT
discriminative, non-autoregressive head, which cannot generate
the rationale an audit prompt asks for. It reaches 0.5 of 10 speci-
fication and 0.667 of 6 measured cases but0 of 33real generated
pairs, answeringequivalent on 35 of 36, and agrees with the two
generative raters at𝜅=0.138,−0.364and−0.057: on two of three
sets it is anti-correlated with them. On the escape case it answers
equivalent, which iscorrect, at a top-1 minus top-2 margin of
0.010: right for no reason a verifier can detect. Changing substrate
does not buy independence, which is a property of theevidence
channel, and only the simulator provides one here. Substituting it
for the missing rater was the obvious move and not one we can
make honestly, so the measured set stops at six cases.
4 What this should change
Each rule is a check an author can run; all eight were violated by
us.(1) Report factor levels beside every variance statistic: a
spread over fewer than two levels of its own axis isunexercised
and can never satisfy a threshold.(2) Treat labels as generated
artifacts: ground a verdict in measurement where you can, abstain
where you cannot, and fuzz structural labelers against preprocessor
lines and comments.(3) Key identity on the delivered digest,
and report the label marginal with every agreement statistic:
𝜅= 1.0on a single-class set means nothing, and a factor level
whose design is another level’s design measures nothing however
consistent its bookkeeping.(4) Do not let a learned score decide
what needs approvalunless it is shown to separate the safe action
from the destructive one; a rule that escalates everything automates
nothing.(5) Make nullity a gate, not a diagnostic: “compiles,
runs, produces numbers” passed three designs that do nothing, and
two of them equal the no-op reference on every trace.(6) Record a
source digest beside every measurement: a binary digest says a
build happened, not which source produced it, and a module name
says less.(7) Fail closed when a factor level has no artifact:
substituting a nearby candidate to keep a grid rectangular destroys
the axis both ways and leaves no trace in the labels.(8) Re-derive,
do not re-run: every repair here was scored against replies and
measurements already on disk, so a label or attribution defect cost
no simulator run and no new model query.
5 Limitations
Each grid is one design set.The2 × 2rectangle shows the seed
and prompt effects surviving simultaneous variation, but the same
code reports𝜏= 0.556then0 .778and78 .16%then23 .50%cross-seed
CV, so every magnitude here is a statement about a specific set of
generated designs.Repeats:0 .0000%is 𝑁= 5per cell (45 runs) and
proves only determinism.Labels:the 33-pair 𝜅 rests on structural
labels that survived our own header-parsing defect only because
we could re-derive them, and no pair in that set is gold-labelled
equivalent, so its verdict-axis agreement is degenerate rather than
reliable.Annotators:the two generative raters the published 𝜅
rests on share one provider; the second provider reproduces the
shared error on the measured and canonical cases but not on the
33-pair set; the one architecturally different rater we could reach
is worse than independent (§3.6); and no rater here is a human.
Validity:we tested role order (0/8verdict flips) and not training-
data contamination, which systematic reviews treat as the dominant
risk [6].A re-ask is disclosed:the second provider’s 10-of-10
canonical verdict score is a retry’s, since the first request returned
no content at all and the retry, shown an identical prompt digest,
parsed.Provenance:three historical unknown commits are left
unrepaired, because writing a plausible SHA into a file that never
measured one would be the defect itself.Scope:one simulator,
one design family, three traces; no RTL flow and no gem5 result is
claimed.
6 Conclusion
We released an audit loop that separates four variance sources,
gates publication on measurementandannotation, and keeps its
evidence. Against the official CHIA ChampSim image it blocked
its own reproducibility claim at78 .16%cross-seed CV, showed
seeds moving artifacts without moving designs, prompt response at
249.18%, and two same-provider auditors agreeing and both wrong
on a measured simulator escape that a second provider repeats
on byte-identical prompts. It also caught ten silent defects in our
own automation, including a labeler that read#include brackets
as comparison operators while the annotators it scored were right.

AI assistance in this work
AI coding and writing tools assisted with implementation, exper-
iment plumbing, and the drafting and editing of this paper. An
AI agent ran the audit loop, wrote and revised the scripts and
the evidence pipeline, and drafted this text under the author’s di-
rection; the author selected the claims, checked them against the
primary artifacts, and is responsible for all content. The evaluation
layer is machine-generated as well: two generative raters from one
provider, a third from a second provider ( Atria-Dawn-Preview,
api.atria-asi.ai, queried 2026-09-24 at temperature 0, per-
case prompt digests in the artifact), a generative labeler shown
to be wrong while the raters were right (Table 1 row 2), a local
discriminative head used as both third annotation substrate and
decision gate (§3.6, Table 1 rows 6), and ten self-audits by the same
agent that produced the code it reviewed. A generated object counts
as evidence only with its producer, version and failure modes at-
tached; the negative verdicts here came from a process that was
not independently audited, so the repository is the thing to check.
